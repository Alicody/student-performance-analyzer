# 🎓 Student Performance Analyzer

A beginner Python project to revise core Python concepts on the journey to AI Engineering.

## 📁 Project Structure

```
Python task/
│
├── README.md                  ← You are here. Project overview and how to run.
├── data/
│   └── student_performance.csv  ← The dataset we will load in Step 5
│
├── steps/
│   ├── step2_variables.py       ← Step 2: Variables, data types, conditions
│   ├── step3_loops.py           ← Step 3: Loops and collections
│   ├── step4_functions.py       ← Step 4: Functions
│   ├── step5_file_handling.py   ← Step 5: File handling and error handling
│   ├── step6_oop.py             ← Step 6: Object-Oriented Programming
│   └── step7_debugging.py       ← Step 7: Debugging and code improvement
│
└── main.py                    ← Step 8: Final assembled application
```

## ▶️ How to Run

```bash
# Run any individual step to practice that concept
python steps/step2_variables.py

# Run the final application
python main.py
```

## 📚 Learning Phases

| Phase | Step | Concepts |
|-------|------|----------|
| 1 | Step 2 | Variables, data types, f-strings, if/elif/else |
| 2 | Step 3 | Lists, dicts, for/while loops, filtering |
| 3 | Step 4 | Functions, parameters, return values, scope |
| 4 | Step 5 | CSV file reading, try/except, input validation |
| 5 | Step 6 | Classes, objects, __init__, methods |
| 6 | Step 7 | Debugging, edge cases, code cleanup |
| 7 | Step 8 | Full application assembly |
